# Security

Please report suspected security vulnerabilities privately instead of opening a public issue.

Until a dedicated private security-reporting address is published, use GitHub's private vulnerability reporting feature on this repository. Include the affected version, impact, and minimal reproduction details. Do not include unrelated personal data, account credentials, cookies, POESESSID values, OAuth tokens, or private build files.

Public bug reports and release questions can use [GitHub Issues](https://github.com/seeyouworks/POE-BOTTARI-Releases/issues).
